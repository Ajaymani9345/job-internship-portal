# JobNest — Job & Internship Portal

A frontend portfolio project built with HTML, CSS and JavaScript.

## Features
- Responsive landing page
- Job listing and search
- Location, type and category filters
- Job details page
- Student registration/login prototype
- Save jobs with LocalStorage
- Apply for jobs with LocalStorage
- Application tracker
- Student profile
- Dashboard
- Mobile responsive design

## Tech Stack
HTML5, CSS3, JavaScript, LocalStorage

## Run locally
Open `frontend/index/index.html` in a browser, or use VS Code Live Server.

## AWS next step
This project is designed to be deployed as a static website to Amazon S3. Later, a backend/API can be added and hosted on EC2.

## Important
Authentication and applications currently use browser LocalStorage. This is a frontend prototype, not production authentication.
